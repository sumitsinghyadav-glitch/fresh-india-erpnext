# Fresh Theme

Fresh India branding for the Frappe v16 desk and login page: green app dock, mint sidebar,
orange primary actions, card layout, and the Fresh India logo.

All styling lives in `fresh_theme/public/css/fresh_theme.css` (desk) and
`fresh_theme/public/css/fresh_login.css` (login / website pages). Bump `THEME_VERSION`
in `hooks.py` after editing CSS so browsers fetch the new file.
